# chess-repertoire

a personal collection of opening repertoire guides built around pawn structure understanding rather than memorized lines.

---

| file | color | opening |
|---|---|---|
| `white / d4` | white | 1.d4 — queen's gambit, london, catalan |
| `white / c4.md` | white | 1.c4 — english opening |
| `black / sicilian defense` | black | 1.e4 c5 — sicilian defense |

---

## philosophy

> learn the structure. the moves follow.

each guide is organized around **pawn families** rather than opening names. the goal is to recognize a position's character and know the correct plan automatically — whether or not you've seen the exact move order before.

---

## how to use this repo

- read the relevant guide before studying games in that opening
- use the **training positions** at the end of each file as practice puzzles
- annotate your own games and add them as you play
- treat every file as a **living document** — update it as your understanding grows

---

## study order

if you're starting from scratch, suggested order:

1. pick one color and one opening
2. read the structure overview and pawn skeleton sections
3. play through 10–15 model games from the recommended players list
4. practice the training positions
5. play games, annotate, repeat
